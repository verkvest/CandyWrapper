# Liltkin

Liltkin is a portrait phone port of Harmony Honey Monroe's looping arcade platformer.
The 144×144 playfield is integer-scaled and letterboxed. Left, right, and jump sit in the thumb zone outside that square. A swipe on the playfield does the same jobs.

Built with [Godot Engine 4.7](https://godotengine.org) (Compatibility renderer).

The original game, art, sound effects, and soundtrack are Harmony Honey Monroe's, under the MIT license. See [LICENSE](LICENSE) and [THIRD_PARTY_LICENSES.md](THIRD_PARTY_LICENSES.md). Upstream page: [harmonymonroe.itch.io/candy](https://harmonymonroe.itch.io/candy).

Bundle id: `es.verkvest.liltkin`

## Phone controls

- Bottom left: move left and right
- Bottom right: jump (hold to jump higher)
- Swipe the playfield: left, right, or up to jump
- Credits: licenses, in the top corner

Keyboard and gamepad bindings from the original game still work.
